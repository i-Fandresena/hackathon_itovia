                             RÉSUMÉ EXÉCUTIF
================================================================================

Système automatisé d'extraction structurée de données depuis les CV des candidats
utilisant Gemini API 1.5 Flash.

DONNÉES EXTRAITES :
  ✓ Informations personnelles (nom, email, téléphone, LinkedIn, GitHub, portfolio)
  ✓ Titre professionnel et résumé
  ✓ Expériences professionnelles (poste, entreprise, technologies, dates)
  ✓ Formation académique (diplômes, institutions, domaines)
  ✓ Projets et réalisations (avec technologies et URLs)
  ✓ Certifications (avec dates et preuves)
  ✓ Langues parlées (avec niveaux CECRL A1-C2)
  ✓ Synthèse (années d'expérience calculées, disponibilité, localisation)

================================================================================
                              ARCHITECTURE
================================================================================

PIPELINE D'EXTRACTION :

  PDF (Client)
      ↓
  Multer (validation, memory storage)
      ↓
  pdf-parse (extraction texte brut)
      ↓
  Gemini 1.5 Flash API (analyse structurée JSON)
      ↓
  Validation & normalisation des données
      ↓
  PostgreSQL (sauvegarde JSON)
      ↓
  React Component CVExtractedData (affichage)

STACK TECHNIQUE :

Backend :
  - Node.js 22.x
  - Express.js
  - Prisma (ORM PostgreSQL)
  - pdf-parse (extraction PDF)
  - Google Generative AI (Gemini API)

Frontend :
  - React 19.2.6
  - React Router 7
  - TypeScript 6.0.2
  - Lucide React (icônes)
  - CSS classique (responsive)

Database :
  - PostgreSQL
  - CandidateProfile (13 champs JSON nouveaux)
